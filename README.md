# AmracShop React (Scaffold)

هذا المشروع هو مسودة واجهة متجر بسيطة مبنية باستخدام React + Vite + TypeScript + Tailwind.

تشغيل محلياً

1) تثبيت الحزم

```bash
npm install
```

2) تشغيل بيئة التطوير

```bash
npm run dev
```

ملحوظات
- البيانات داخلية (mock) داخل src/data/products.ts
- حالة السلة تُدار عبر zustand
